# Build Windows — MIAR EDITA

## Requisitos
- Node.js 18+
- npm
- Windows 10/11

## Passos
1. Abra o terminal na pasta do projeto.
2. Execute:
   ```powershell
   npm install
   npm run dist
   ```
3. O instalador será gerado na pasta dist.

## Resultado esperado
- Arquivo .exe do instalador Windows
- Atalho no menu Iniciar e área de trabalho
