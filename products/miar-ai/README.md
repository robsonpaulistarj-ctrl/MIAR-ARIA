# MIAR AI

Aplicativo desktop Electron para Windows com assistente de IA, voz, memória e automação.

## Como executar após baixar e descompactar

1. Abra o terminal na pasta do app:
   ```bash
   cd products/miar-ai
   ```
2. Instale as dependências com pnpm:
   ```bash
   pnpm install
   ```
3. Inicie o app:
   ```bash
   pnpm start
   ```

No Windows, você também pode usar:
```bash
start.bat
```

## O que precisa estar instalado

- Node.js 18+
- pnpm (recomendado)

Se você ainda não tem pnpm:
```bash
corepack enable
```

## O que fazer depois de descompactar

- Baixe o ZIP do repositório ou clone com `git clone https://github.com/miarmaakyu/MIAR-ARIA.git`
- Descompacte em qualquer pasta do seu computador
- Abra o terminal na pasta `products/miar-ai`
- Execute `pnpm install` e `pnpm start`

## Build Windows

- `pnpm run dist`
